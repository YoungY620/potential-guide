# 美术规范（Art Bible）

全部美术为**原创**：材质纹理由分形噪声程序生成并烘焙为独立 PNG 材质文件（`public/assets/materials/`，可用 `npm run bake:materials` 重新生成或由美术手绘替换），单位/建筑造型在运行时以多层材质渲染管线（基色渐变 → 剪裁纹理叠加 → 装甲接缝/铆钉/脉络 → 边缘光与内阴影 → 高光 → 能量辉光）组合烘焙上屏。**无任何外部/商业素材**。

渲染管线：`src/render/materials.ts`（材质库：噪声纹理、材质填充、边缘光、高光、接缝、铆钉、脉络、辉光、烘焙缓存）→ `src/render/sprites.ts`（每个单位/建筑的材质造型定义 + 动态部件）→ `src/render/terrain.ts`（地图）→ `src/ui/Icon.tsx`（UI 图标）。

## 材质库（独立材质文件）

| 文件 | 用途 | 观感 |
| --- | --- | --- |
| `brushed.png` | 秩序机器装甲、建筑 | 水平拉丝金属 |
| `grain.png` | 高光板、骨刺、岩石 | 细颗粒 |
| `chitin.png` | 入侵体外壳、蹂躏者 | 硬质几丁质脊纹 |
| `flesh.png` | 囊体、核心、口器 | 湿亮生物斑纹 |
| `crystal.png` | 电容晶体、数据晶片 | 切面晶体 |

文件缺失时引擎自动回退到程序实时生成（离线可用性不受影响）。

## 1. 秩序机器（The Wardens / 守望机群）— 已实装

**主题**：工业机械、模块装甲、实体服务器与防火墙。硬朗折角、铆接钢板、青色数据辉光 + 橙色工程点缀。

### 轮廓语言
- 以**直线折角多边形**为主（六边形地基、梯形装甲板、矩形伺服塔）。
- 单位 = 底盘 + 模块化附加件（肩甲、撞锤、线圈、机械臂），一眼可辨职能。
- 建筑 = 几何基座（六边形/梯形）+ 垂直结构（塔、烟囱、天线）。

### 图标
线性 SVG 图标（`src/ui/Icon.tsx`）：剪影化最关键特征（磁轨枪、撞锤三角、电弧叉、晶体、炮管），青色/橙色双色。

### 特效与动画
- 行走：腿/履带正弦摆动，机身 ±1.5px 起伏；悬浮单位（弧光）3s 周期浮沉。
- 攻击：枪口/线圈闪光（attackFlash 0→1 衰减 6/s）；投射物：磁轨=青色短划线，电弧=折线闪电，火焰=橙色菱形。
- 建造：虚线脚手架框 + 顶部进度弧 + 主体渐显（45%→85% 不透明度）。
- 死亡：钢蓝色碎片迸溅 + 冲击环。
- 选中：青色椭圆圈 + 四角刻度线。

### 轮廓语言

- 体型越大骨刺越多、囊泡越密集；核心单位带旋转环结构。

## 3. 超维协议体（The Axioms / 超维协议体）— 规范 + 3 单位概念（未实装）

**主题**：几何光构、悬浮晶格、护盾与空间折叠。完美对称、半透明光面、棱镜分色。

### 轮廓语言
- **严格几何对称**（三角形、四面体、六芒星、莫比乌斯环），无机械细节、无有机细节。
- 单位=核心几何体 + 环绕晶格碎片（公转）；建筑=悬浮多面体阵列。
- 所有边缘带 1px 棱镜描边（青→紫渐变）。

### 材质与色板
| 用途 | 色值 |
| --- | --- |
| 光构主体 | `#dfe9ff`（近白蓝） |
| 晶格折射 | `#8a7dff`（紫罗兰） |
| 护盾 | `#7dd6ff` 30% 透明 + 六边形网格纹 |
| 折叠裂隙 | `#c77dff` |
| 核心奇点 | `#ffffff` + 强径向辉光 |

材质：半透明光面（globalAlpha 0.7–0.9）+ 叠加混合（`lighter`）辉光。

### 尺寸基准
- 小型单位半径 12–16，大型单位 22–30；建筑占地 2×2–5×5，主体悬浮于基座上方 8–14px（投影用软椭圆）。

### 单位概念

**AX-1「棱卫」Prism Sentinel（基础战斗）**
- 轮廓：正四面体核心，三片三角光翼 120° 对称环绕公转（周期 4s）。
- 职能：中程光束（瞬时命中光束特效，非投射物）。
- 动画：受击时光翼瞬缩再展开；攻击时三翼聚光于顶点。

**AX-2「帷幕行者」Veilwalker（突袭/机动）**
- 轮廓：扁平六芒星盘面 + 拖尾裂隙纹；移动时沿路径留下 0.4s 渐隐折光残影。
- 职能：高机动骚扰；短距"折叠"位移（冷却制，特效=原地六边形网格坍缩 + 落点重构）。
- 动画：非悬浮而是"滑移"，无上下浮沉；转向时盘面倾斜 ≤20°。

**AX-3「圣裁晶座」Judicator Lattice（重型/护盾支援）**
- 轮廓：三重同心六边形晶格环（各反向旋转 6s/9s/14s 周期）+ 中央悬浮二十面体。
- 职能：为周围友军提供护盾泡（六边形蜂窝纹理半球，受击涟漪）；弱攻击。
- 动画：护盾开启时环体加速旋转 2s；晶格环随护盾量明暗。

### 特效规范（全阵营通用约束）
- 特效必须语义化：伤害=暖色迸溅，治疗=绿色上行粒子，护盾=蓝色六边网格，空间效果=紫色几何坍缩。
- 单屏特效粒子上限 600，冲击环与迸溅可叠加但透明度随数量衰减。

## 4. 地图美术规范（已实装）

- 基底：深蓝电路板（`#121d30 → #142136` 对角渐变）+ 细网格（α0.16）。
- 电路走线：260 条确定性伪随机走线（青/橙，α0.10–0.24）+ 端点焊盘。
- 数据流：通路沿线 3px 青色数据包，90px/s 流动。
- 阻挡（电路岭）：`#22314e` 凸起 + 顶部青色高光边。
- 资源：数据晶片=青色晶簇（高度随储量）；流能=橙色喷口（射流脉动）。
- 感染区：紫色渐变团 + 酸绿脉络。
- 战争迷雾：未探索 92% 黑、已探索不可见 43% 黑，低分辨率柔化放大。

## 5. UI 美术规范（已实装）

- 深蓝玻璃拟态面板（`rgba(10,17,28,.92)` + 1px `#22314e` 边）。
- 命令卡按钮：图标 + 名称 + 右上角快捷键字标 + 底部进度条/冷却扫层 + 数量角标。
- 警报：左边框色条（波次=红、完工=绿、研究=紫）。
- 色觉友好：三套替代色板（绿/红/蓝色弱），切换影响小地图敌我色、血条与威胁等级色。
