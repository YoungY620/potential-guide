# 快捷键表

默认键位可在游戏内「快捷键」界面改绑（持久化保存，冲突自动检测）。改绑范围：全局命令。命令卡快捷键（训练/建造/研究/技能）来自单位与建筑的数据定义，标注在按钮右上角。

## 全局命令

| 功能 | 默认键 | 说明 |
| --- | --- | --- |
| 攻击移动 | A | 然后左键点目标位置；沿途自动接敌 |
| 停止 | S | 立即清空指令队列 |
| 保持位置 | H | 不追击，只攻击射程内敌人 |
| 巡逻 | P | 然后左键点终点，在两点间往返攻击移动 |
| 取消 | Esc | 取消目标型命令 → 清除选择 → 打开暂停菜单 |
| 定位警报 | Space | 镜头跳到最新警报位置 |
| 暂停/继续 | F10 | 暂停时模拟与全部计时冻结 |
| 打开菜单 | F9 | 暂停并打开菜单 |
| 切换单位子组 | Tab | 混合选择时按 战斗单位→工人→建筑 循环 |

## 编队

| 功能 | 按键 |
| --- | --- |
| 创建编队 | Ctrl + 数字键（1–0） |
| 追加到编队 | Shift + 数字键 |
| 选择编队 | 数字键 |
| 定位镜头到编队 | 快速双击数字键 |

## 鼠标

| 操作 | 效果 |
| --- | --- |
| 左键 | 点选；Shift+左键 增减选择；拖框多选；双击选屏幕内同类 |
| 右键 | 智能命令：敌人→攻击，资源→采集，受伤友军→修复，在建建筑→续建，其他→移动 |
| Shift + 命令 | 追加到指令队列 |
| 小地图左键 | 移动镜头（可拖动）；目标型命令时确认目标点 |
| 小地图右键 | 向该处下达智能命令 |
| 滚轮 | 以光标为中心缩放（0.45×–1.6×） |

## 镜头

方向键平移；鼠标推到屏幕边缘滚屏（设置中可关闭）；小地图点击/拖动。

## 命令卡快捷键（数据驱动）

| 内容 | 键 | 来源 |
| --- | --- | --- |
| 训练 接续者 | S | 核心主堡 |
| 训练 哨卫 | A | 制造厂 |
| 训练 壁垒 | D | 制造厂 |
| 训练 弧光投射者 | F | 制造厂（需数据链塔） |
| 训练 修补匠 | G | 制造厂（需数据链塔） |
| 建造 制造厂 | F | 接续者 |
| 建造 数据链塔 | U | 接续者 |
| 建造 电容塔 | C | 接续者 |
| 建造 防火墙炮塔 | T | 接续者 |
| 研究 复合装甲 | P | 数据链塔 |
| 研究 超频协议 | O | 数据链塔 |
| 设置集结点 | R | 生产建筑 |
| 战术技能 电磁脉冲 | Q | 全局（需视野） |
| 战术技能 纳米修复云 | W | 全局 |

注：命令卡键与全局键共享键盘上下文（如 A 既是攻击移动也是哨卫训练键）；当前激活面板决定含义——选中建筑时为训练，选中单位时为命令。快捷键界面的冲突检测会同时列出这两类。
