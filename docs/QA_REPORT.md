## 已知限制（非阻断）

1. macOS 包未签名（无 Apple 开发者证书），首次打开需在「隐私与安全性」放行或右键打开。
2. 玩家单位攻击不检查目标视野（敌方始终可见时即可被攻击）；不影响单机体验。
3. Windows 版本未在当前 macOS 机器上构建（同一源码 `electron-builder --win` 可产出 `AI Defense RTS.exe`）。

## 测试期发现并修复的缺陷（诚实记录）

1. 波次单位出生点位于瘟巢占地内部 → 单位被困形成死锁集群；改为占地外生成并允许受困单位自由走出。
2. 波次首路径点与瘟巢瓦片重合 + 渗扰出生在占地内 → 百单位淤积卡死；路径点外移后 stuck=0。
3. 建筑成本在建造到达时扣除 → 与持续生产竞争资源导致建造静默流产；改为下单即扣款（RTS 惯例），位置失效全额退款。
4. 入侵核心射程/伤害过强且沿路径徘徊 → 终局僵局；调整数值并改为直扑主堡的决胜行为，脚本玩家 14.8 分钟获胜。
5. 边缘滚屏将未初始化鼠标坐标 (0,0) 误判为屏幕角落 → 镜头持续漂移（用户实机反馈）；改为鼠标进入时记录真实坐标，12s 截图验证稳定。
