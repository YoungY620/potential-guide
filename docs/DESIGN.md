# 设计与架构说明

## 1. 设计目标

- 原创单人 RTS：指挥防御型 AI 机体抵御入侵体；操作手感、快捷键与信息架构对标竞技 RTS（左键选择/右键智能命令/A 攻击移动/编队/子组/警报定位），但所有名称、剧情、单位、美术、UI、音效均为原创。
- 完全离线、一键启动的桌面应用。
- 可复现：同一随机种子 → 同一对局（模拟层不使用 `Math.random`、不依赖墙钟）。

## 2. 分层架构

```
┌───────────────────────── Electron 主进程 ─────────────────────────┐
│  electron/main.ts：窗口、离线加载、QA 截图钩子、退出即清理        │
└───────────────────────────────────────────────────────────────────┘
┌─────────────────────────── React UI 层 ───────────────────────────┐
│  src/ui/：HUD（资源/容量/威胁/警报/命令卡/生产队列/多选卡片）      │
│  主菜单、暂停、设置、快捷键改绑、教学、胜负结算                    │
├────────────────────────── 输入层 ────────────────────────────────┤
│  src/input/：选择（点选/框选/双击/子组）、镜头、键位映射+冲突检测  │
├────────────────────────── 渲染层 ────────────────────────────────┤
│  src/render/：Canvas 2D。程序化矢量美术、地形离屏缓存、迷雾、      │
│  特效粒子、小地图。只读 World，不改状态                            │
├────────────────────────── 模拟层 ────────────────────────────────┤
│  src/game/：纯 TypeScript，无 DOM。固定步长 20 ticks/s             │
│  world（状态）→ commands（校验+应用）→ systems（移动/指令/战斗/    │
│  生产）→ ai（波次导演）→ fog（战争迷雾）→ sim.step（管线）         │
└───────────────────────────────────────────────────────────────────┘
```

关键约束：

- **模拟层纯净**：`src/game/` 不引用 DOM、Canvas、localStorage、墙钟；可在 Node 中直接被 vitest 驱动，这也是自动化测试与性能基准的基础。
- **数据驱动**：单位/建筑/升级/技能全部定义在 `src/game/data/*.ts`（属性、成本、快捷键、解锁条件、描述）。命令卡按钮、快捷键冲突检测、UI 图标均从这些数据生成，新增单位只需加数据与造型函数。
- **命令校验与应用分离**：`validate*` 返回 `{ok, reason}`（资源不足/容量不足/科技未解锁/目标无效/冷却中），UI 用于禁用提示；`applyCommand` 才改状态。
- **事件总线**：模拟产生 `GameEvent`（射击/命中/爆炸/死亡/建造完成/警报…），渲染层转粒子特效，音频层转音效；互不干扰。

## 3. 固定步长与确定性

- 20 ticks/s 固定步长；`GameController.frame` 用累加器把可变帧时间切成整数 tick，渲染帧间做位置插值（`prevPos → pos`）。
- 暂停 = 不再推进累加器，模拟与全部计时（冷却、波次、动画计时依赖的 tick）冻结。
- 确定性手段：种子化 mulberry32 RNG；实体按 id 排序后逐 tick 处理；波次时刻表在世界创建时由种子生成；适应波组成是当前玩家军力的纯函数。测试：同种子 1200 tick 后状态哈希逐字节一致。

## 4. 核心系统

### 4.1 地图
128×128 瓦片（32px），静态阻挡为两条"电路岭"，围出北/中/南三条进攻通路；3 处资源区（主矿 + 2 处扩张）；感染区为视觉地标。瓦片网格同时服务寻路与建筑放置校验。

### 4.2 寻路与群体移动
- A*（8 向、octile 启发、二叉堆）+ 视线拉直平滑；建筑占地动态写入网格。
- 局部避让：基于空间哈希的分离转向（separation），卡死 1.5s 触发重寻路。
- 采集/建造/修复/巡逻/攻击移动都是指令状态机（`systems/orders.ts`），Shift 追加 = 指令队列。

### 4.3 战斗
- 属性数据化：生命/速度/伤害/攻速/射程/视野/碰撞半径；近战即时伤害、远程追踪投射物、AoE 溅射（弧光、蹂躏者、入侵核心）、建筑伤害加成（噬建虫）、维修支援（修补匠）。
- 目标获取按 6 tick 错峰扫描（空间哈希），驻留/保持/巡逻行为各异。

### 4.4 敌方波次导演（`src/game/ai.ts`）
- 9 个预定波次（60s 侦察 → 700s 最终入侵核心），路线由种子从 3 条通路选择，提前 10s 警报。
- 4 分钟后有轻量渗扰保持压力。
- **适应波（至少一次，实际两次）**：读取玩家战斗容量 vs 炮塔数——龟缩流 → 噬建虫+母巢虫；大军流 → 母巢虫+喷吐者；弱势 → 噬虫海。第二波适应波规模 ×1.5 并加精英。
- 胜利 = 摧毁入侵核心；失败 = 核心主堡被毁。

### 4.5 战争迷雾
瓦片级可见性：visible（每 2 tick 重算）+ explored（持久）。渲染为 128² 低分辨率画布放大柔化；小地图同步显示；EMP 需要目标点视野。

## 5. 输入与操作映射

- 左键：点选（Shift 增减）/拖框/双击选屏内同类；确认目标型命令（A/P/技能/放置）。
- 右键：智能解析目标（敌→攻击；资源→采集；友伤→修复；在建→续建；否则移动）；小地图右键同样有效。
- 编队：Ctrl+数字创建、Shift+数字追加、数字选择、双击数字居中镜头；Tab 在混合选择中循环子组（战斗/工人/建筑分组），命令只下达给当前子组。
- 镜头：方向键、边缘滚屏（可关）、滚轮以光标为中心缩放、小地图点击/拖动。
- 改绑：`src/input/keymap.ts` 数据驱动，持久化到 localStorage，`detectConflicts` 报告冲突键。

## 6. 渲染与美术

- 地形一次性绘制到 2048² 离屏画布（电路板基底、网格、电路走线、感染区、岭体），每帧裁剪 blit；车流动画（数据包沿通路流动）每帧叠加。
- 所有单位/建筑为程序化矢量造型（`src/render/sprites.ts`），两套视觉语言：秩序机器=折角工业装甲+青/橙辉光；入侵体=半有机数字增生物+紫/酸绿。含行走摆动、悬浮起伏、攻击闪光、受眩晕标记、建造脚手架与进度弧。
- 特效：事件驱动的粒子/冲击环，爆炸触发屏幕震动（设置可减弱）。
- 迷雾画布 128² 放大柔化；选择圈、血条、命令标记旗、路径虚线、集结点、放置幽灵（绿/红 + 射程预览）、技能范围圈均为世界空间叠加。

## 7. UI 信息架构

顶栏（资源/容量/威胁等级+下波 ETA/对局时间/FPS/暂停/菜单）· 右上警报列表（点击跳转）· 底部：小地图 | 选择面板（单选详情/多选卡片/生产队列可点击取消）| 数据驱动命令卡（含禁用原因 tooltip 与进度条）| 战术技能面板（冷却扫层）。教学为真实对局内的 8 步检查单。

## 8. 音频

WebAudio 运行时合成（无任何音频文件）：选择/移动/攻击/建造/完工/升级/警报/射击/爆炸/胜利/失败，主音量+音效+音乐三路独立音量，低音持续氛围音乐。

## 9. 持久化与打包

- localStorage 保存设置与键位（`aidrts.settings.v1` / `aidrts.bindings.v1`），重启保留。
- electron-builder 产出 `release/mac-arm64/AI Defense RTS.app`（dir 目标，未签名）；唯一入口，双击即玩；无端口、无服务器、无残留进程（`window-all-closed → app.quit()`）。

## 10. 性能策略

- 空间哈希做邻近查询；目标扫描错峰；迷雾每 2 tick；A* 仅在下令/卡死时触发；投射物与粒子有上限；离屏地形避免每帧重绘。
- 基准（`scripts/bench.mjs`）：200 单位混战 0.49 ms/tick（20 TPS 预算 50ms 的 ~1%）；24000 tick（20 分钟）内存浸泡堆增量为负（无泄漏）。

## 11. 已知取舍

- 敌方可被攻击迷雾外目标（玩家单位不检查目标视野）；不影响体验，列为后续改进。
- 寻路为单单位 A* 而非流场；200 单位规模下实测充足，更大规模可换流场。
- macOS 包未签名（无开发者证书），首次打开需 Gatekeeper 放行。
